GARAGEMETRIC CLOUD

Видалити акаунт

Ви можете назавжди видалити GarageMetric Cloud акаунт і пов’язані хмарні дані безпосередньо в застосунку або через цю сторінку.

Видалення в застосунку GarageMetric

  1. Відкрийте GarageMetric та увійдіть у свій акаунт.
  2. Відкрийте Ще → Хмарний акаунт.
  3. Натисніть Видалити акаунт.
  4. Перегляньте попередження та підтвердьте другий запит на безповоротне видалення.

Після успішного видалення застосунок виконає вихід і очистить робочий простір видаленого акаунта на поточному пристрої.

Видалення через веб

Ця форма автентифікується безпосередньо в Supabase-проєкті GarageMetric. Ваш пароль передається до Supabase Auth через HTTPS і не зберігається цим сайтом GitHub Pages.

Видалення акаунта є безповоротним. Використовуйте цю форму лише для акаунта, який справді потрібно назавжди видалити.

Що буде видалено

  • Ваш GarageMetric Cloud автентифікаційний акаунт.
  • Синхронізовані записи про транспорт, план ТО, історію сервісу та нагадування, пов’язані з акаунтом.
  • Хмарні резервні копії GarageMetric, пов’язані з акаунтом.
  • Приватні хмарні вкладення, збережені для цього акаунта.

Якщо ви видаляєте акаунт через застосунок, робочий простір поточного пристрою та заплановані нагадування GarageMetric також очищаються. Інші пристрої можуть зберігати локальні офлайн-копії, доки дані GarageMetric на них не буде очищено або застосунок не буде видалено. Після видалення хмарного акаунта ці пристрої більше не зможуть авторизуватися в ньому.

Зберігання після видалення

Після успішного видалення GarageMetric прибирає активний акаунт і пов’язані прикладні дані. Постачальники інфраструктури можуть тимчасово зберігати обмежені резервні, технічні або аудиторські записи, якщо це необхідно для надійності сервісу, запобігання шахрайству або виконання юридичних зобов’язань.

Потрібна допомога?
