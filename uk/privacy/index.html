Політика конфіденційності

Дата набрання чинності: 31 жовтня 2026 року · Застосовується до GarageMetric 1.0 і цього вебсайту.

GarageMetric — застосунок для обліку технічного обслуговування та історії сервісу транспорту. Ця політика пояснює, які дані обробляє застосунок, для чого вони використовуються, де зберігаються хмарні дані та як їх можна видалити.

1. Які дані обробляє GarageMetric

Дані акаунта

Якщо ви створюєте GarageMetric Cloud акаунт, служба автентифікації обробляє вашу електронну адресу, ідентифікатор акаунта, дані сесії автентифікації та технічні дані безпеки, необхідні для входу. GarageMetric не отримує ваш пароль у відкритому вигляді.

Дані гаража та технічного обслуговування

Введені вами дані можуть містити марку, модель, рік, назву або нікнейм транспортного засобу, VIN, номерний знак, пробіг, мотогодини або цикли заряджання; плани технічного обслуговування; історію сервісу; вартість деталей і робіт; нотатки та налаштування нагадувань.

Фото та документи

Коли ви додаєте фото або документ до сервісного запису, GarageMetric обробляє вибраний файл. Доступ до камери або фототеки запитується лише тоді, коли ви використовуєте відповідну функцію вкладень. Файли зберігаються локально та можуть також завантажуватися до приватного хмарного акаунта під час використання Cloud Sync або Cloud Backup.

Метадані синхронізації

GarageMetric використовує технічні метадані, зокрема згенеровані ідентифікатори пристроїв, версії сутностей, ревізії синхронізації та часові мітки, щоб безпечно узгоджувати зміни між авторизованими пристроями.

2. Як використовуються дані

  • Для роботи гаража, плану ТО, історії сервісу та нагадувань.
  • Для автентифікації GarageMetric Cloud акаунта.
  • Для синхронізації даних між вашими авторизованими пристроями.
  • Для створення та відновлення приватних хмарних резервних копій за вашим запитом.
  • Для зберігання й синхронізації сервісних вкладень, які ви вирішили завантажити.
  • Для виявлення та розв’язання конфліктів синхронізації без прихованого перезапису змін.

3. Локальні дані та хмарні сервіси

GarageMetric спроєктований так, щоб залишатися корисним офлайн. Локальні дані застосунку зберігаються на вашому пристрої. Якщо ви входите в акаунт і використовуєте хмарні функції, GarageMetric використовує Supabase для автентифікації, бази даних і приватного файлового сховища.

Хмарні дані можуть оброблятися на інфраструктурі Supabase та його субпідрядників. Мережевий трафік передається через зашифровані HTTPS-з’єднання. Хмарні записи прив’язані до акаунта, а сервісні вкладення зберігаються у приватному, а не публічному файловому сховищі.

4. Quick Add та AI

У GarageMetric 1.0 Quick Add використовує локальний парсер, якщо production endpoint віддаленого AI не увімкнено. Версія 1.0 не надає віддалену голосову AI-обробку в production-застосунку та не запитує дозвіл на запис із мікрофона. Якщо в майбутній версії GarageMetric буде ввімкнено віддалену AI-обробку, цю політику буде оновлено до введення такої обробки.

5. Сповіщення

GarageMetric може планувати нагадування про технічне обслуговування та користувацькі нагадування на вашому пристрої. Дозвіл на сповіщення використовується для цих нагадувань. GarageMetric 1.0 не використовує сповіщення для реклами.

6. Реклама, продаж даних і відстеження

GarageMetric 1.0 не містить рекламних SDK, не продає ваші персональні дані та не використовує дані гаража для міжзастосункової реклами або поведінкової реклами.

7. Зберігання та видалення даних

Локальні дані залишаються на пристрої, доки ви не видалите їх, не очистите дані застосунку, не очистите відповідний робочий простір акаунта або не видалите застосунок. Хмарні дані залишаються пов’язаними з вашим акаунтом, доки їх не буде видалено засобами GarageMetric або разом з акаунтом.

Після успішного видалення акаунта GarageMetric видаляє хмарний автентифікаційний акаунт, синхронізовані записи GarageMetric, хмарні резервні копії та приватні хмарні вкладення, пов’язані з цим акаунтом. Робочий простір акаунта на поточному пристрої також очищається. Постачальники інфраструктури можуть тимчасово зберігати обмежені резервні або технічні записи, якщо це необхідно для надійності сервісу, запобігання зловживанням або виконання юридичних вимог.

Перегляньте сторінку видалення акаунта, щоб дізнатися про видалення з застосунку та через веб.

8. Безпека

GarageMetric використовує автентифікований доступ, правила бази даних, прив’язані до акаунта, приватне файлове сховище та зашифровану передачу даних для хмарних функцій. Жоден спосіб електронного зберігання або передачі даних не може гарантувати абсолютну безпеку.

9. Діти

GarageMetric призначений для власників транспортних засобів і ведення обліку технічного обслуговування та не розроблений для дітей молодше 13 років.

10. Зміни цієї політики

Політика може оновлюватися, якщо GarageMetric додає або змінює функції, постачальників сервісів чи практики обробки даних. У разі суттєвих змін дата набрання чинності у верхній частині сторінки буде оновлена.

11. Контакти

З питань конфіденційності звертайтеся до розробника GarageMetric через публічний профіль github.com/uglov. Не публікуйте паролі, токени автентифікації або приватні дані гаража у відкритих GitHub issues.
